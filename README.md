🧠 Kotlin AI Quiz App

An interactive, Android application built with Kotlin that generates dynamic, personalized quizzes on-demand using Google AI Studio (Gemini API). Users can enter any topic, and the app will instantly generate structured multiple-choice questions with real-time feedback.

✨ Features

• Google AI Studio Integration: Leverages the Gemini API via Google AI Studio to generate smart, contextual trivia and academic questions.
• Instant Quiz Generation: Enter any topic or keyword to create a unique set of multiple-choice questions in seconds.
• Real-Time Scoring: Track correct and incorrect answers instantly with immediate score summaries.
• Clean Android UI: A modern, native Android user interface built with Kotlin (and Jetpack Compose / XML).

🚀 Tech Stack

• Language: Kotlin
• AI Engine: Google AI Studio (Gemini SDK for Android)
• Architecture: MVVM (Model-View-ViewModel)
• UI Framework: Jetpack Compose (or XML Material Design - adjust as needed)
• Asynchronous Programming: Kotlin Coroutines & Flow

🛠️ Setup & Installation

1. Clone the repository:bash
git clone https://github.com
Use code with caution.
2. Get a Gemini API Key:
	• Go to Google AI Studio.
	• Create an API Key.
3. Configure the API Key:
Add your API key to your local configuration file (e.g., local.properties or your environment variables):properties
GEMINI_API_KEY=your_google_ai_studio_api_key_here
Use code with caution.
4. Build and Run:
	• Open the project in Android Studio.
	• Sync the Gradle files.
	• Run the app on an emulator or a physical Android device.
